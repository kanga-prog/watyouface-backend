# MPD PostgreSQL — référence documentaire

## Types et conventions

PK : `BIGINT GENERATED BY DEFAULT AS IDENTITY` ; `String` : `VARCHAR` (ou `TEXT` pour contenu long) ; `LocalDateTime` : `TIMESTAMP`; `Instant` : `TIMESTAMPTZ`; boolean : `BOOLEAN`; prix/solde cible : `NUMERIC(12,2)` plutôt que `DOUBLE PRECISION` pour une valeur monétaire même simulée.

## Tables principales

| Table | Colonnes clés et contraintes cibles |
|---|---|
| `users` | id, username/email UQ NN, password NN, accepted_contract NN default false, avatar_url, role NN check USER/ADMIN, contract_id FK |
| `contract`, `user_contract` | contenu/version/date ; user_contract FK, acceptation/date, UQ(user_id,contract_id) cible |
| `post`, `comment`, `likes` | author_id ; commentaires vers post/video ; likes user + post/video avec unicité cible |
| `conversations`, `conversation_users`, `messages` | participants UQ conversation/user ; message conversation/sender/receiver NN, contenu max 2000 cible |
| `listings`, `wallet`, `transaction` | seller NN/buyer nullable/status ; wallet user UQ ; transaction listing UQ cible, amount > 0 |
| `video`, `video_share` | vidéo/uploader ; partage vidéo/sender/receiver |
